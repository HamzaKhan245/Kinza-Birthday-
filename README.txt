# Happy Birthday, Kinza ❤️

A romantic, mobile-responsive birthday website made with HTML, CSS, and JavaScript.

## Files
- `index.html` — the content and structure
- `style.css` — colors, layout, responsive styling, and animations
- `script.js` — surprise popup, floating hearts, confetti, and button interactions

## Run on a computer
1. Download and unzip `kinza-birthday-website.zip`.
2. Keep all three files in the same folder.
3. Double-click `index.html` to open it in a browser.
4. For editing, open the folder in VS Code. You can use the Live Server extension, or just open `index.html` in your browser.

## Run on an Android phone
1. Extract the ZIP using your phone's Files app.
2. Keep `index.html`, `style.css`, and `script.js` together in the same folder.
3. Tap `index.html` and choose Chrome or another browser.
4. If your file manager cannot open local HTML files properly, use the publishing steps below and open the website link instead.

## Publish it online for sharing
### GitHub Pages (free)
1. Sign in to GitHub and create a new public repository, for example `kinza-birthday`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment options, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then save.
6. Wait a minute or two. GitHub will show your website URL in the Pages section. Open it on your phone to test it, then share the link with Kinza.

## Personalize the message
Open `index.html` in a text editor and edit the paragraphs inside the `letter-copy` section and the surprise popup. You can change the name by searching for `Kinza` and replacing it wherever it appears.

## Notes
- An internet connection is needed for the optional Google Fonts to load; the website still works without them.
- The website does not collect or send personal data.
- Test the published link on your phone before sharing it.
